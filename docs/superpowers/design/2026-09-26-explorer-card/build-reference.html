The spec, in one table

HeadEyebrow 10.5px caps teal · title 15px semibold · the committed filter as a hue dot on the title line, × on hover (always on touch). No chip anywhere.
Hint11.5px muted, under the title, as today.
Heading rowHairline under it. Left: the axis, 10.5px caps muted (Network / Country / Snapshot / Layer). Right: the view's one setting, then the stepper — 10.5px caps bold, full ink. Snapshots' LIVE becomes dot + word here; History's Same scale sits beside its stepper.
Row grid16px glyph · 100px name · tag home (flex) · 56px bar · 56px figure · 12px slot. Name 12.5px full ink, ellipsis. Figure 12.5px mono semibold, right-aligned, tabular. Tag home: chips at 10px, text at 10.5px muted, ellipsis with full text on hover. Slot: ✓ committed (click again releases) · › opens only · empty.
BarThe figure's share of the busiest row, in the row's hue; a level's bars at 60% of the parent's hue.
Level blockInset wash panel. One line: name 10.5px caps muted bold · meaning 11.5px muted · the parent's total right, mono. Rows drop to dim ink and medium figures. A second depth nests a panel one wash deeper.
Level meaningsBy composition · Which layers each node runs. By city · provider · Where the nodes sit, and who hosts them. By network · Who anchored into this tick, and how much. By snapshot · Each snapshot the network anchored here. By signer · The validators that sealed it. By node · Each machine in this cohort.
SemanticsA network row that only opens (Snapshots) wears › and no wash. Filter is set only by the top bar and the Hypergraph hub / network row; Geography and Snapshots selections never set it (screen 1, option B, as built for Geography today).
PagingMono 10.5px muted, centred under the list, where a list pages (Snapshots, History).
