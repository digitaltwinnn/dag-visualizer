Fixed in every option: the glyph column is 16px and holds a dot, a country code, or nothing; the name column is a fixed width and ellipsises; the figure is 46px, right-aligned, tabular; the slot is 12px and holds ✓, ›, or nothing. Node rows put the id in the name column in mono and their state in the tag home. My recommendation is A: one row height everywhere, and truncation only where a provider name is long, with the full name on hover. Click one and tell me here.
